# 实车准入补充：2026-10-28 数据后的下一步

本轮实车已经断开，以下为下次现场准备，不是启动或运动授权。G0仍未通过；G1–G5仍须逐关书面确认。现有原准入流程见robot/准入关卡.md。

## G0：只读补采清单

| 项目 | 预期读数/证据 | 停止条件 |
| --- | --- | --- |
| 身份 | 用户现场核对主机指纹；已有地址仅历史记录 | 指纹变化、目标不明或需未知权限 |
| 时钟 | UTC可信；记录timedatectl/同步源与ROS时间，时间戳递增 | 年代异常、倒退、未来样本，禁止自行改钟 |
| 相机 | 持续接收、源stamp无倒退/未来、raw/compressed同帧一致 | 源时间不合格即G0失败；画面按接收时间显示不替代此项 |
| 雷达 | 复查频率和束结构，保存有效FOV/盲区记录、帧名和外参依据 | 断流、时间异常、自车反射/无效扇区未解释 |
| 里程计与TF | 只读查看已存在接口、驱动配置和TF链；静态外参来自测量 | 需要启动底盘或发送命令才能核查时先停，不伪造TF |
| 几何/运动学 | 操作者填写车体最外侧尺寸、轮/转向结构、传感器位置 | 无现场测量；不凭mini4wd配置名推断能原地转 |
| 负载 | 记录只读检查CPU/内存、话题频率与延迟，注明工况 | 不拿20.7%传感器负载推断SLAM+Nav2满载能力 |
| 原始证据 | 先复制已有静止bag，核对已登记SHA，再新录不少于60秒有效消息 | SHA不符、包损坏、只录到进程启动时间而非消息时长 |

离线驱动候选必须先由timestamp_source_audit.py精确识别实际源码；unknown/vendor/mixed一律拒绝准备。候选仅固定上游文件，不是完整驱动。审核、构建、切换overlay、重启相机或改时钟须另有明确维护授权及原目录/哈希回滚证据。未知源时钟不能通过改网页判据掩盖。

G0回滚：本轮只读检查无配置变更，退出检查器并保留新文件即可；任何后续维护都先备份原安装/启动方式，失败恢复原overlay/参数并重新采样。恢复旧版不等于G0通过。网络断开时不自动重连、重启或恢复控制。

## 仿真建议进入下一阶段的条件

保留当前独立验收全部门限：覆盖率、可观测轮廓误差/覆盖、地图保存、返航、无几何重叠、真值质量与进程正常退出各自都要通过；realism=on且每布局/起点至少5个固定种子，不只报平均值。通过率与Wilson区间按每格报出。不能只看completed或一次最好结果；assumed参数通过也不是实车准入。

目前主动观测A/B尚未证明任务成功率提升。完整扫掠范围有未知格时，P0应停止并请求人工介入；当前实车不建议进入G1，更不建议自主探索。后续需要先取得真实有效FOV、足迹和已有安全空间证据，才决定仿真模型是否应调整。不要把轮子离地、人工手扶或“附近看着空”当作软件已证明可旋转。

G1/G2阶段的硬件watchdog、急停、链路失效、速度/加速度/制动与yaw校准仍按原关卡清单，由人在现场操作；本文件不提供启动底盘或转轮命令。每关交付检查、预期值、停止与回滚后等待对应“通过关卡N”。
