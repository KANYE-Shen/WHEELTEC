# 房间仿真：第一次怎么操作

项目在 `D:\虚拟c盘\WHEELTEC`。启动用 `.cmd` 文件；`.md` 是说明文档。

## 先认识两个窗口

| 窗口 | 你看到的是什么 | 主要用途 |
| --- | --- | --- |
| Gazebo | 有墙、有家具、有小车的三维房间 | 看小车在虚拟现场怎么走、有没有碰撞 |
| RViz | 雷达点、二维地图、位置箭头和规划路线 | 看小车测到了什么、算法如何定位和规划，在地图上下达目标 |

Gazebo 的三维房间是我们预先搭好的场景。RViz 中的地图由 SLAM 根据激光和里程计逐步生成；小车不会直接读取房间模型当地图。

## 先把视角调舒服

**Gazebo**：滚轮缩放；按住左键拖动平移；按住滚轮拖动旋转视角。右击小车并选 `Move to` 可以把视野移过去，选 `Follow` 可以跟随小车。左上方橙色圆钮用于播放/暂停，控制整个仿真时间，驾驶时保持运行。这些操作只是调整观察位置，不是开车。[Gazebo Fortress 操作说明](https://gazebosim.org/docs/fortress/gui/)

**RViz**：先点顶部 `Move Camera`。当前是俯视图：滚轮缩放、按住滚轮拖动平移、左键拖动旋转地图视角。左侧 `Displays` 的复选框可以临时隐藏某层。[RViz Humble 操作说明](https://github.com/ros2/ros2_documentation/blob/humble/source/Tutorials/Intermediate/RViz/RViz-User-Guide/RViz-User-Guide.rst)

RViz 中主要看这几层：

| 显示 | 含义 |
| --- | --- |
| `Map` 的白色区域 | 已观察到的空地 |
| `Map` 的黑色线/块 | 墙或障碍 |
| 灰色或未展开区域 | 尚未观察，不能当作可通行空地 |
| `LaserScan` 的红色点 | 当前一圈雷达打到的位置 |
| `Robot odometry` 的绿色箭头 | 里程计经过地图坐标变换显示的估计位置与朝向 |
| `Planned route` 的蓝线 | 到目标的全局路线 |
| `Controller path` 的黄线 | 控制器当前接收并用于跟踪的路线 |

只在移动或导航时才有路线，未下目标时没有蓝线是正常现象。

## 体验一：自己开车，看地图补全

1. 如果之前的仿真还开着，先去启动它的黑色终端按 `Ctrl+C` 结束，避免同时开两套。
2. 双击根目录 `打开房间仿真.cmd`，等待两个窗口打开，RViz 出现第一片地图。
3. 双击 `打开键盘遥控.cmd`，会多开一个遥控终端。点击这个终端，把输入法切到英文。
4. 用下面的键慢慢移动，一边看 Gazebo 的小车，一边看 RViz 的地图。绕过障碍、换几个观察位置，原来被挡住的区域会逐渐出现。

| 按键 | 动作 |
| --- | --- |
| `i` | 前进，0.15 m/s |
| `,`（英文逗号） | 后退，0.15 m/s |
| `j` | 原地左转，0.5 rad/s |
| `l` | 原地右转，0.5 rad/s |
| `k` 或空格 | 停止 |
| `q` 或 `Ctrl+C` | 停止并退出遥控 |

按住或连续点按方向键才持续运动；超过 0.35 秒没收到新的按键会自动发停止指令。长按刚开始时若短暂停一下，是系统的按键连发延迟。按键要发给遥控终端，在 Gazebo 或 RViz 里按 `i` 不会控制小车。

手动驾驶时自己避开墙和家具，雷达显示并不会自动替键盘遥控刹车。切换到点选导航前，在遥控终端按 `q` 退出；不要让遥控和自主导航同时发送速度。

## 体验二：在地图上指定位置

1. 退出键盘遥控，保持房间仿真运行。
2. 在 RViz 已经显示出来的白色空地里选一个近处目标，离墙和家具留出小车通行的宽度。
3. 点顶部 `Nav2 Goal`，在目标处按住左键，拖出一个短箭头再松开。
4. 观察蓝色路线和 Gazebo 中的小车。当前按目标位置到达，不要求终点车头必须与拖出的箭头一致。
5. 目标正在执行时，`Navigation 2` 面板原来的 `Reset` 按钮会变为 `Cancel`，点它中止任务。没有任务时显示 `Reset` / `Pause`，这时不用找 `Cancel`。想接管驾驶，先取消导航，再打开键盘遥控。

建图模式中，面板可能显示 `Navigation: active`、`Localization: inactive`：当前定位由 SLAM Toolbox 提供，面板的 Localization 指的是 AMCL，这个 inactive 不表示建图失败。加载已存地图的模式才使用 AMCL。`Pause` 会停用 Nav2 节点，`Reset` 会清理 Nav2 节点，普通驾驶和发目标不需要点这两个按钮。按钮状态依据 [Nav2 Humble 面板实现](https://github.com/ros-navigation/navigation2/blob/humble/nav2_rviz_plugins/src/nav2_panel.cpp)。

临时封路时小车会等待，每5秒重新尝试规划，最多约5分钟；障碍移除后原目标可以继续。需要提前停止时点 `Cancel`。

不要把目标放在黑色障碍上或未观察区域。若导航没开始，先看 `Navigation 2` 面板是否就绪，以及启动终端是否仍在加载；地图和导航节点需要先启动。

## 体验三：保存地图，重启后继续导航

1. 建图仿真运行时，先让小车停稳，再双击 `保存当前地图.cmd`。地图按时间保存到 Linux 的 `/home/wheeltec/wheeltec_sim_ws/data/maps/`。
2. 在原仿真启动终端按 `Ctrl+C` 结束。
3. 双击 `打开已存地图导航.cmd`，加载最近一次保存的地图，进入固定地图定位模式。
4. 每次加载地图后，先点 RViz 的 `2D Pose Estimate`：在你估计的小车位置按住左键，朝实际车头方向拖动再松开。本场景重启后的起点是地图坐标 `(0, 0)`，车头朝 `+X`（默认画面的右侧）。还未给定初始姿态时，可能暂时看不到转换到地图上的雷达或箭头。这个操作是在告诉定位算法“小车大概在这里”，不会把 Gazebo 里的车瞬移过去。
5. 等红点与墙体贴合后，再用 `Nav2 Goal` 指定目标。固定地图定位时不会把保存的地图重新画一遍。

在 Windows 资源管理器地址栏输入下面这一行可查看地图文件：

```text
\\wsl.localhost\WHEELTEC-Ubuntu-22.04\home\wheeltec\wheeltec_sim_ws\data\maps
```

没有保存过地图时，先完成一次建图和保存，再使用已存地图入口。

## 体验四：让小车自主探索

关闭已有仿真，双击 `开始自主探索.cmd`。不要再开键盘遥控或同时点发其他导航目标；小车会自行选择探索目标。观察地图是否逐渐展开，以及任务终端给出的结束状态、地图保存位置和返回起点的结果。

探索终端输出 `completed` 才表示地图已保存且小车已经返回；`incomplete` 表示还有未解决区域或触发任务限制，`failed` 表示保存、定位、返回等步骤失败。结束后场景继续显示，仍用启动终端 `Ctrl+C` 退出。

## 结束与常见情况

- **完整退出**：在启动房间的黑色终端按 `Ctrl+C`，等待进程结束；遥控终端用 `q` 退出。关闭 RViz 只会结束显示，结束整次实验用启动终端。
- **小车完全不动**：先看 Gazebo 是否暂停，再确认键盘焦点在遥控终端、输入法为英文，或 Nav2 已接受目标。
- **初始几秒只有红点，没有地图**：等 SLAM 发布第一张地图；持续没有地图时查看启动终端的错误和左侧 `Map` 状态。
- **地图被移出屏幕**：用 `Move Camera` 加滚轮/中键找回来；最直接的方法是退出并重新双击入口，恢复默认视角。
- **想重新建一张图**：结束当前仿真，再打开 `打开房间仿真.cmd`，这是新的建图会话。
