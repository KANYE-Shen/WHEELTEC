WHEELTEC 房间仿真操作指南

从 D:\虚拟c盘\WHEELTEC 双击入口文件。.cmd 用来启动，.md 是说明文档。

先关掉旧仿真，再打开一套新的；用启动它的黑色终端 Ctrl+C 结束。

根目录入口怎么选

三个启动入口每次选一个；切换模式先在原启动终端按 Ctrl+C。

入口用途
启动_手动建图.cmd自己驾驶建图，也可在已观察区域点选导航
启动_自主探索建图.cmd自动选点、建图、保存并返回起点
启动_已有地图导航.cmd加载最近地图，给定初始姿态后点选导航
控制_键盘遥控.cmd仿真运行时打开驾驶终端
地图_保存当前成果.cmd建图时保存地图、位姿图及参考方向
帮助_操作指南.cmd在浏览器打开本指南

Gazebo：看虚拟现场

  • 滚轮缩放；左键拖动平移；按住滚轮拖动旋转视角。
  • 右击小车 → Move to 移过去看；Follow 跟随小车。
  • 左上橙色圆钮播放/暂停整个仿真。驾驶时保持运行；调整视角不会开动小车。

RViz：看数据、地图和路线

  • 先点顶部 Move Camera，再用滚轮缩放、中键拖动平移、左键拖动旋转俯视图。
  • Nav2 Goal：下达目标位置；2D Pose Estimate：告诉定位算法小车大概在哪、朝向哪里。
  • 左侧 Displays 复选框可以显示或隐藏图层。

地图怎么读

白色：已观察到的空地
黑色：墙或障碍
灰色/未展开：还没观察到
红点：当前雷达测量
绿色箭头：里程计经地图变换后的估计姿态
蓝线：规划出的全局路线
黄线：控制器收到并用于跟踪的路线

还没下目标时没有路线。先选已经看到的白色空地，避开黑色障碍和未观察区域。

体验一 · 自己开车，看地图补全
  1. 在旧仿真的启动终端按 Ctrl+C 结束，再双击 启动_手动建图.cmd。
  2. 等 Gazebo 和 RViz 打开，RViz 出现第一片地图。
  3. 双击 控制_键盘遥控.cmd。点击遥控终端，把输入法切到英文。
  4. 慢慢移动小车，换几个观察位置，看原来被家具挡住的区域逐渐出现。
按键动作
i前进，0.15 m/s
, 英文逗号后退，0.15 m/s
j / l原地左转 / 右转，0.5 rad/s
k / 空格停止
q / Ctrl+C停止并退出遥控

按住或连续点按才持续运动；0.35 秒没有新按键就自动停止。长按刚开始短暂停一下，是系统按键连发的延迟。按键要发给遥控终端，在 Gazebo 或 RViz 里按不会开车。

手动驾驶时自己避开墙和家具。切换到点选导航前，先在遥控终端按 q 退出，避免遥控和导航同时发速度。
体验二 · 点地图，让小车自己过去
  1. 退出键盘遥控，保持房间仿真运行。
  2. 在 RViz 中选一处近距离的白色空地，离墙和家具留出通行宽度。
  3. 点顶部 Nav2 Goal，在目标处按住左键，拖出短箭头后松开。
  4. 看蓝色路线及 Gazebo 中的小车。当前按位置到达，不要求终点车头与箭头一致。
  5. 执行任务时，Navigation 2 中的 Reset 会变成 Cancel；点 Cancel 取消任务。要接管驾驶，先取消，再开键盘遥控。

临时封路时小车等待，每5秒重新尝试规划，最多约5分钟；障碍移除后原目标继续。需要提前停止时点 Cancel。

没有任务时面板显示 Reset / Pause，这时不用找 Cancel。普通驾驶和下目标不需要点 Reset 或 Pause；它们会清理或停用导航节点。

建图时看到 Navigation: active、Localization: inactive 是正常的：此时 SLAM 提供定位，面板的 Localization 指 AMCL。加载已存地图后才用 AMCL。
体验三 · 保存地图，重启后继续导航
  1. 建图运行时，让小车停稳，双击 地图_保存当前成果.cmd。手动保存也会记住当前房间布局和起点，之后恢复同一场景。
  2. 在原仿真启动终端按 Ctrl+C 结束。
  3. 双击 启动_已有地图导航.cmd，加载最近一次保存的地图。自主探索保存的地图会恢复所记录的房间布局和起点；没有场景记录的历史地图沿用原房间。
  4. 每次加载后都先给初始姿态：点 2D Pose Estimate，在估计的小车位置按住左键，朝实际车头方向拖动再松开。本房间重启后在地图 (0, 0)，车头朝 +X，即默认画面的右侧。
  5. 等红色雷达点贴合地图中的墙，再用 Nav2 Goal 指定目标。

初始姿态是在告诉算法“小车大概在这里”，不会把 Gazebo 里的车瞬移过去。尚未指定时，可能看不到转换到地图上的雷达或位置箭头。

把下面路径复制到 Windows 资源管理器地址栏，可查看按时间保存的地图：

\\wsl.localhost\WHEELTEC-Ubuntu-22.04\home\wheeltec\wheeltec_sim_ws\data\maps

还没保存过地图时，先完成一次建图和保存，再用已存地图入口。

体验四 · 选择陌生房间，自主探索并回放
  1. 关闭已有仿真，双击 启动_自主探索建图.cmd。
  2. 选择布局：1 原房间、2 L形房间、3 家具房间、4 弯通道、5 凹角房间；回车选原房间。
  3. 选择起点 0、1、2，终端会列出位置和车头；回车选0。
  4. 等 Gazebo、RViz 和浏览器过程页打开。不要同时使用遥控或点击其他导航目标。

浏览器过程页怎么看

页面约每5秒读取一份记录。地图来自 SLAM，绿色箭头是估计车头，橙线是已走轨迹，蓝线是规划路线。右侧显示位置、相对起点车头的角度、数据年龄及缺失项。角度以首次有效车头为0°，逆时针为正。

  • 播放 / 暂停、底部时间滑块、倍速：回看已记录的过程；地图和已走轨迹只显示到所选时刻。
  • 回到实时：重新跟随新数据；图层复选框切换地图、激光、车头、轨迹和路线。
  • 暂停仿真或连接中断后保留最后数据，并显示最后记录时刻；页面暂停播放不会暂停小车。
  • 路线超过5秒未更新时显示虚线，并保留更新年龄。

completed 表示地图已保存并已返回；incomplete 表示仍有未解决区域或触发限制；failed 表示保存、定位、返回等步骤失败。独立地图验收 是基于真值的本次最终评分；普通探索明确显示未评分。任务完成不等于覆盖率和精度验收通过。

完成、退出与离线回放

任务到达终态后立即生成 replay.html，场景与网页仍保留。完整结束请在启动终端按 Ctrl+C；中途 Ctrl+C 会保存已有过程，记录为人工中止。关闭网页不会停止探索。

终端会打印本次过程目录。Windows资源管理器打开下列位置，在本次时间目录内双击 replay.html 即可回放，无需服务器：

\\wsl.localhost\WHEELTEC-Ubuntu-22.04\home\wheeltec\wheeltec_sim_ws\data\runs

地图仍保存到 data/maps/ 并更新最近地图。旁边的 .simulation.json 保存布局、起点与场景校验，“已有地图导航”据此恢复同一个房间。场景源文件改动后会明确报出不匹配。

直接重复某个场景：在项目根目录的PowerShell运行 .\simulation\Start-Room.ps1 -Explore -Scenario l_shape -Spawn 2。场景参数为 baseline、l_shape、clutter、bent_passage、recess；省略起点时用0。

遇到这些情况

  • 三维画面闪白、闪黑或房间消失：2026-10-23 已加入适配 WSLg 的画面同步补丁；旧窗口不会自动更新，请在原启动终端按 Ctrl+C 后重新打开入口。
  • 小车不动：看 Gazebo 是否暂停；遥控终端是否有键盘焦点且为英文输入；导航是否已接受目标。
  • 最初几秒没有地图：等 SLAM 发布第一张地图；持续没有时看启动终端及左侧 Map 状态。
  • 看不到房间或地图：滚轮缩小、中键拖动找回视野；退出重开入口可恢复默认视角。
  • 完整结束：遥控用 q 退出，房间启动终端用 Ctrl+C 退出。只关 RViz 会结束显示。
  • 重新建图：结束当前仿真，再双击 启动_手动建图.cmd。
