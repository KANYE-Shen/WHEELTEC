## 改动与安全边界

视频显示增加receiving/receive_age（目标端单调接收时间，1秒超时），与原fresh（源时间戳校验）分开；GET camera只提供仍在接收的图像。原stamp/age/fresh不变，不放宽定位、扫描或控制验收。已检测到的时间戳告警在本页保留，避免告警自身每秒插入/移除；这类画面不用于定位或安全判定。

浏览器串行获取并先解码新JPEG，React替换后释放旧URL，卸载时中止请求。HTTP失败、视频停止或网页状态离线时隐藏缓存，不以缓存伪装实时画面。
