# 车端静态准备与回归

仅编写与静态检查，没有连接、部署、启动真实驱动或发送实车速度。默认config/robot.json硬件未核实，拒绝启动；没有生成关卡批准文件。

安全链路为Nav2→平滑→碰撞监视→最终看门狗→已核实驱动。看门狗使用单调时钟，启动保持零速，命令/操作者心跳超时锁定停车；恢复连接或释放急停不自动续行，明确解除保持还需新鲜心跳与零命令。驱动自身失效超时必须核实，因为软件被强杀/断电不能保证发布最后一个零。

静态审查发现准入依赖循环：若G1架空测试先要求G2地面制动测量，无法按顺序测试。先加用例，原实现报Measured braking distance required；修复将地面完整校准/制动要求限定在G3以上，watchdog明确当前gate，完整导航/探索强制G4/G5。修复次数1，不自动批准任何关卡。尺寸从统一校准JSON生成，车体长宽没有measured证据时拒绝运行。

12项robot纯逻辑/只读检查回归通过；校准离线工具4项通过。compileall、bash -n通过；systemd-analyze verify没有模板语法错误，但WSL全局netplan/snapd配置及Windows挂载权限产生提示，真实Linux属主/权限、服务账户和启动仍未验证。

尚未验证：真实轮速方向/制动、硬件急停、断链停车、驱动唯一命令源、velocity_smoother/collision_monitor运行联动、网页HTTPS代理/鉴权端到端、板上资源。不能把纯逻辑用例作为G1通过。关卡清单见robot/准入关卡.md。
