# WHEELTEC：网页监看与二维自主建图

在电脑浏览器中监看 WHEELTEC / RDK X5 小车，通过现有网页发起自主探索或手动接管。建图、定位、导航和安全控制运行在车端；电脑通过固定指纹 SSH 连接，负责显示和用户操作。

## 打开网页终端

依赖和前端已准备好时，在 Windows 上启动现有入口：

```powershell
& 'D:\Python\python.exe' -B -u 'D:\虚拟c盘\WHEELTEC\console\start.py'
```

在浏览器打开 **http://127.0.0.1:8766**。如果网关已经运行，无需再启动一个。首次安装及其他平台步骤见[网页终端说明](console/README.md)：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r console/requirements.txt
npm ci --prefix console/frontend
npm run build --prefix console/frontend
.venv\Scripts\python.exe console/start.py --check
.venv\Scripts\python.exe console/start.py
```

`--check` 检查本机依赖和已构建的前端，不检查小车在线情况。

连接小车热点后，在未连接页面输入“小车 SSH 密码”并点击“连接小车”。网关复用事先配置的实车目标与可信指纹，经 SSH 读取适配器令牌；密码不保存在配置或仓库。适配器已在线时直接连接；缺失时，现有停车准备流程核对条件并按原配置补启动缺失组件，必要时校时，不解锁或自动探索。失败时显示原因，可按页面提示显式重试。详见[停车准备记录](setup/verification/2026-11-06-web-auto-prepare.md)。

**网页打开、SSH 认证、适配器在线、任务运行是不同状态。** 首次使用需要维护者配置唯一实车目标及固定主机指纹；指纹不符先核查身份，不自动信任。不要把密码发到聊天或命令行。

## 在网页操作

- 页面展示地图、雷达、位置、相机和日志；相机只用于监看。地图支持拖动、`+ / −` 缩放和居中，滚轮不缩放。
- 现场安全、相应实测范围获准且准备完成后，由操作者点击“自主探索”。用户也可选择“远程接管”：按住 W/S 前后、A/D 转向，松键停车；Space 停车并保持。
- 低/中/高三挡默认上限为 **0.03 / 0.06 / 0.10 m/s**，自主探索每次从中挡启动。这是配置，不是实测制动能力。
- 自主或启动时，在非输入区按 WASD 会先停止任务并切换接管；普通键或可见窗口失焦不取消自主。手动模式失焦、页面隐藏或关闭、连接/心跳失效均停车保持，重连不自动恢复原按键或任务。
- 维护终端是完整 SSH shell。打开前需要最终 watchdog 新鲜的停车确认；它不是运动沙箱。网页目前没有任意点选导航目标。

详细交互及故障处理见[网页终端说明](console/README.md)和[接口文档](console/API.md)。软件停车不等于现场硬件急停或实际制动距离已经验证。

## 厂家底座与项目补充

车端 `/home/wheeltec/wheeltec_ros2/src` 已包含底盘与传感器驱动、车体模型、SLAM Toolbox、Nav2，以及 `wheeltec_robot_rrt2` 的自动探索目标生成。这里包括厂家集成的上游组件，并不全由厂家原创。

本仓库车端启动复用厂家硬件入口及官方 SLAM/Nav2。2026-11-08 停车部署后，网页自主任务配置调用厂家的 `global_rrt`、`local_rrt` 和 `filter` 寻找候选点；现有任务层检查净空、管理导航取消、存图和返航，保留网页原有操作和安全链，不启动厂家找箱行为树或第二套底座。网页任务从当前地图确定采样范围、从小车安全配置取得几何参数，用户无需在网页输入这些参数；原 CLI 和仿真默认行为不变。

**厂家候选接入已停车部署，尚未启动实车探索验收。** 厂家包依赖、采样范围限制和独立实验入口见[探索器说明](src/wheeltec_explore/README.md#厂家-rrt-候选后端实验性)。厂家二进制的构建方式和车端探索表现仍需核验；部署与恢复依据见[停车部署记录](setup/verification/2026-11-08-vendor-web-deploy.md)。

项目补充集中在网页接管、速度来源仲裁、操作者心跳与指令失效保护、目标取消和失败处理、按任务存图返航及诊断。地图保存与规划仍调用标准服务；有额外职责不意味着每层都必须长期自写。

## 仿真与保留入口

本项目保留 WSL2、ROS 2 Humble 和 Gazebo Fortress 仿真。根目录六个入口只用于既有仿真流程，每次只选择一个启动模式：

| 双击文件 | 用途 |
| --- | --- |
| `帮助_操作指南.cmd` | 打开图文操作指南 |
| `启动_手动建图.cmd` | 启动房间仿真，手动建图 |
| `控制_键盘遥控.cmd` | 打开仿真键盘遥控 |
| `地图_保存当前成果.cmd` | 保存当前仿真地图及位姿图 |
| `启动_已有地图导航.cmd` | 加载地图定位并在 RViz 导航 |
| `启动_自主探索建图.cmd` | 仿真自主探索、存图和返航 |

切换模式前，在原启动终端按 Ctrl+C；不要同时启动两套房间仿真。详见[仿真操作指南](simulation/操作指南.md)和[仿真说明](simulation/README.md)。仿真真值仅用于独立评估，不提供给在线建图、导航或探索。

Windows 源码目录为 `D:\虚拟c盘\WHEELTEC`；WSL 中访问为 `/mnt/d/虚拟c盘/WHEELTEC`，构建及数据工作区为 `/home/wheeltec/wheeltec_sim_ws`。地图、bag 和运行结果的位置见[数据说明](data/README.md)。

## 当前状态与证据

曾有网页接管和用户触发的自主运动记录，也有 TF 过期、目标无进展和不完整任务；稳定完成探索、存图及返航尚未通过完整验收。2026-11-06 的网页停车准备有实际使用记录，首次密码连接能否无需显式重试完成冷启动尚未单独确认。实际硬件制动和 MCU 独立超时仍待验证。

车端现有的 85% 指目标附近局部已知格比例，不是整间房间覆盖率。用户要求的边界 70%＋内部 30% 加权、85% 自动换区及窄口分区仍是研究目标；本地试验未部署，参考地图仅用于离线核验。[区域策略和负结果](setup/verification/2026-11-05-region-reference-and-latency.md)。

实车按[三阶段准入清单](robot/准入关卡.md)安排连接与校准、人工建图/导航、监督自主探索；各阶段实际操作需相应授权。历史受监督例外不等于校准通过或新的运动授权。原始结果、失败与中断记录见[验证索引](setup/verification/轮次索引.md)和[replay buffer](replay%20buffer/README.md)；后者是证据库，不自动训练或回放实车动作。
